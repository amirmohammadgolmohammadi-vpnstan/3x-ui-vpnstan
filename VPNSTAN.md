# VPNSTAN

This repository is the VPNSTAN-branded build of the supplied admin6501 RBAC fork.

- Panel version label: 3.11.0
- Branding: VPNSTAN
- Internal service/database paths remain `x-ui` for compatibility with existing installations.
- GPL-3.0 licensing from the upstream project is retained.

## Important

The supplied fork contains a number of changes newer than the historical upstream v3.11.0 release.
This build preserves the supplied fork rather than replacing it with upstream files, so RBAC/reseller,
plans, groups, hosts, Telegram shop, 2FA, LDAP, SMTP, HWID and related fork features remain intact.
